Vérba

A lightweight local-first language practice app.

Operational · local-first PWA · actively refined through use

Vérba is a small offline-friendly practice tool for vocabulary matching, text completion, and grammar forms. Language packs can be installed locally and used without an account or backend.

Open Vérba Language packs

Vérba must be opened through a local web server. Run: node scripts/serve-site.mjs

Product vision

Practice exactly what you need, without turning language learning into a platform.

Vérba is designed for short, targeted language practice. Learners can use ready-made packs, focus on specific practice pools, add their own material, or exchange portable packages. The application stays local-first, requires no account, and is built around fast vocabulary, text and grammar drills.

Product principles

Local first

Learning data stays on the device.

No account

Practice starts without registration.

Bring your own content

Paste, import or create your own material.

Targeted practice pools

Practice today's topic instead of the entire library.

Portable packages

Move and exchange content as simple files.

Offline friendly

Installed content remains available without a connection.

From need to validation

Vérba evolved from a simple question: how can a learner practise exactly the material that matters today, while keeping the content portable and the workflow lightweight?

Need

User needs

Practise a specific set of material quickly, without navigating through a prescribed course.

Validation

User validation

Using Vérba in real study sessions exposes friction that tests alone do not: repeated vocabulary led to coverage-based rotation, ambiguous text gaps led to meaning hints, and difficult corrections now remain visible until they have been read.

Define

Product requirements

Words, Text and Forms drills; Match, Choose and typed Translate; named pools, custom content, portable packages and useful progress without gamification.

Validate

System validation

Multiple languages work across all three practice areas, custom packages remain usable offline, pools select only intended content, and no account or backend is required.

Design

Technical design

A static installable PWA using browser-local storage and IndexedDB, portable JSON content, no backend, and GitHub Pages deployment.

Verify

Integration testing

Package import/export round-trips, durable local additions, IndexedDB persistence, generated hosting paths, and offline/PWA behaviour.

Specify

Component design

Package and pool selection, answer checking, content parsers, progress and mastery tracking, and adaptive word rotation.

Test

Unit / logic testing

Imported-content parsing, strict and tolerant comparison, pool membership, vocabulary rotation, and scoring and progress rules.

What Vérba does

Words

Match vocabulary, choose between translations, or type the answer from memory.

Text

Fill annotated gaps at several difficulty levels, with optional translations and advanced clues.

Forms

Practise articles, conjugations, endings and other grammar forms with rule-based feedback.

Your content

Create local material, organise it into pools, and import or export portable packages.

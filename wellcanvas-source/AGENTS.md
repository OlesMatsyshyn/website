# Project Rules

- Work only inside this project folder.
- Keep code minimal, readable, and close to the current Next.js App Router structure.
- Use TypeScript, Tailwind CSS, ESLint, `src/`, and `@/*` imports.
- Use mock data until persistence is explicitly requested.
- Do not add Supabase, OpenAI, authentication, barcode scanning, external UI libraries, or new architecture without a clear request.
- Preserve calm, neutral nutrition language.
- Favor fast mobile daily interactions and large touch targets.
- Run lint and production build after meaningful code changes.
